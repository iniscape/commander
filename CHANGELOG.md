# Changelog

## 0.1.1

Changes:

- Jump to the first or last image with PgUp and PgDn.
- Zoom a full-screen image by wheel, then drag it.
- Leave the viewer on the last image it showed.
- Close the viewer with F3 too.
- Select and copy text in the text viewer.
- Open with → and go up with ← in Full view.
- View a file with → in Full view.
- Rename in place with F2 on every platform.
- Rename a file by clicking its name under the cursor.
- Add Rename first in the Files menu, showing F2.
- Show F8 for Delete in the Files menu.
- Sort folders by size, date and extension too.
- Sort by ⌥F1 to ⌥F5 on macOS, and by Attr anywhere.
- Mark a run of rows with ⇧↑ and ⇧↓.
- Drop the marks with a plain click on a row.
- Unmark all with Select All when all rows are marked.
- Show marked rows more clearly in dark mode.
- Keep a marked name plain, not bold, under the cursor.
- Edit the path line with ⌘L, or ⌃⇧L off macOS.
- Render Markdown in the viewer, spaced as on GitHub.
- Follow changes to the viewed file in the viewer.
- Fix the viewer's context menu in dark mode.
